01 · LÓGICA

Lógica proposicional

Estudia enunciados que pueden tomar uno de dos valores: verdadero o falso.

  • AND (∧): da verdadero cuando las dos proposiciones son verdaderas.
  • OR (∨): alcanza con que una sea verdadera.
  • NOT (¬): cambia verdadero por falso y viceversa.
Ejemplo: “Está nublado Y hace frío” solo es verdadero si se cumplen ambas partes.
Poné a prueba tu lógica

Si A es verdadera y B es falsa, ¿cuánto vale A AND B?

Falso: la operación AND exige que ambas sean verdaderas.
02 · CONJUNTOS

Conjuntos y leyes de De Morgan

Un conjunto reúne elementos y suele escribirse entre llaves.

A = {1, 2, 3}　 B = {3, 4, 5}
Unión: A ∪ B = {1, 2, 3, 4, 5}
Intersección: A ∩ B = {3}
Diferencia A − B = {1, 2}

Las leyes de De Morgan relacionan el complemento de una unión con la intersección de los complementos, y el complemento de una intersección con la unión de los complementos.

Comprobá

¿Qué elemento comparten A y B?

El número 3; por eso A ∩ B = {3}.
03 · NUMERACIÓN

Sistemas decimal y binario

El sistema decimal usa diez dígitos (del 0 al 9). El binario trabaja únicamente con 0 y 1.

El binario 101 equivale a 5 en decimal.
En binario: 10 + 01 = 11.

En una conversión a decimal, cada posición binaria representa una potencia de 2.

Desafío binario

¿A qué número decimal equivale 110?

6, porque 1×4 + 1×2 + 0×1 = 6.
04 · INFORMACIÓN

Medición de información

Los datos digitales se miden con unidades que indican cuánta información se almacena.

  • Bit: unidad mínima, puede ser 0 o 1.
  • Byte: grupo de 8 bits.
  • KB, MB, GB y TB: unidades de mayor capacidad.
En la convención escolar habitual: 1 KB = 1024 bytes y 1 MB = 1024 KB.
Desafío de almacenamiento

¿Cuántos bits forman 3 bytes?

24 bits, porque 3 × 8 = 24.
05 · ESTRUCTURAS

Vectores

Un vector es una lista ordenada de datos. Cada elemento tiene una posición determinada.

A = [2, 4, 6]　 B = [1, 3, 5]
Suma: A + B = [3, 7, 11]
Resta: A − B = [1, 1, 1]

Para sumar o restar vectores de igual tamaño, se opera con los elementos que ocupan la misma posición.

Desafío de vectores

¿Cuál es la suma de A y B?

[3, 7, 11].
06 · PYTHON

Programación lógica

Las condiciones permiten que un programa elija qué instrucciones ejecutar según se cumpla o no una expresión.

numero = 8
if numero > 5:
　 print("Mayor")
else:
　 print("Menor")

AND, OR y NOT combinan o invierten condiciones. Los bucles y las listas sirven para repetir acciones y recorrer datos.

Desafío de Python

¿Qué palabra muestra el programa del ejemplo?

“Mayor”, porque 8 es más grande que 5.
07 · RELACIONES

Producto cartesiano

El producto cartesiano A × B reúne todos los pares ordenados posibles con el primer elemento tomado de A y el segundo de B.

A = {1, 2}　 B = {a, b}
A × B = {(1,a), (1,b), (2,a), (2,b)}

Una relación está formada por pares ordenados. Una función es una relación donde cada elemento del dominio tiene exactamente una imagen.

Desafío de pares ordenados

Si ambos conjuntos tienen 2 elementos, ¿cuántos pares aparecen en A × B?

4 pares, ya que 2 × 2 = 4.
08 · MATRICES

Matrices y Pixel Art

Una matriz organiza valores en filas y columnas. Puede utilizarse para representar información o imágenes digitales.

[ [1, 0, 1],
　[0, 1, 0],
　[1, 0, 1] ]

En Pixel Art, cada valor puede representar un píxel. Así se forman dibujos usando una cuadrícula. También existen operaciones entre matrices, como suma y resta, según sus dimensiones.

Desafío de matrices

¿Cuántas filas y columnas tiene la matriz del ejemplo?

Tiene 3 filas y 3 columnas: es cuadrada de orden 3.
